# Basic Chatbot AI

This is a basic chatbot AI built using an API with HTML, CSS, and JavaScript.

## Features
- Uses an API to process chatbot responses
- Simple user interface built with HTML and CSS
- JavaScript handles chatbot interactions

## Installation
1. Clone the repository:
2. Open the project folder and run the application in a local development server.

## Usage
- Open `index.html` in a browser to interact with the chatbot.
